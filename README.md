## GC-PlayerLogger

A lightweight and configurable Minecraft Player Logger for Paper & Purpur 1.21.11.

## Features
- 📋 Player commands
- 💬 Player messages
- 🎮 Player actions
- 🔐 /login & /register logging with password masking
- 🔔 In-game staff alerts
- 💬 Discord webhook logging
- 📁 Daily log files
- 🚨 Sensitive event alerts
- ⚙️ Fully configurable
- 🔄 Update-safe configuration system

## Commands
- /plog reload
- /plog alerts
- /plog status
- /plog test

## Permissions
- playerlogger.admin
- playerlogger.alert
- playerlogger.exempt

Requirements: Minecraft 1.21.11 | Paper / Purpur

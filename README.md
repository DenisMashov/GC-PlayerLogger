GC-PlayerLogger

A lightweight player logging plugin for Paper/Purpur 1.21.11.

Features
📝 Logs all player commands
💬 Logs player chat messages
🎮 Logs important player actions
🔐 Supports /login and /register logging with password masking
💬 Sends logs to Discord via webhook
🔔 In-game alerts for staff
📁 Daily local log files
🚨 Sensitive command/block alerts
⚙️ Configurable logging options
🔄 Safe configuration updates without deleting existing settings
💾 Automatic config backups before updates
🚫 playerlogger.exempt support
Commands
/plog reload
/plog alerts
/plog status
/plog test
/plog test chat

Permissions
playerlogger.admin
playerlogger.alert
playerlogger.exempt
